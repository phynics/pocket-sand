# Alternates

Marks this app has worn, kept so one can be put back without hunting for the file.

`assets/icon.png` is the icon in use; the files here are not referenced by the
build. Each is the full square, 1024×1024, with no alpha channel — an iOS icon
with transparency is rejected, and a resize that quietly adds one is a surprise
at submission rather than now.
